## 🔍 معرفی

این پروژه یک سیستم پیشرفته طبقه‌بندی رادیوگرافی دندانی را با استفاده از یادگیری انتقالی (Transfer Learning) و DenseNet121 پیاده‌سازی می‌کند. این سیستم قادر است:

- **طبقه‌بندی** ساختارهای دندانی در سه دسته: عاج (dentin)، مینا (enamel) و پالپ (pulp)
- **تشخیص** و مکان‌یابی ساختارهای دندانی در تصاویر رادیوگرافی کامل
- **آموزش** کارآمد روی Mac M4 با استفاده از Metal Performance Shaders (MPS)
- **ارزیابی** با معیارها و تصویرسازی‌های جامع

### قابلیت‌های کلیدی

- ✅ دقت بالای طبقه‌بندی (بیش از 98% دقت اعتبارسنجی)
- ✅ استنتاج بلادرنگ روی Mac M4
- ✅ تشخیص اشیاء با کادرهای محدودکننده
- ✅ معیارهای ارزیابی جامع
- ✅ رابط خط فرمان آسان

## ✨ ویژگی‌ها

### معماری مدل
- **DenseNet121** پیش‌آموزش داده شده روی ImageNet
- یادگیری انتقالی با تنظیم دقیق
- نرخ یادگیری جداگانه برای backbone و classifier
- بهینه‌سازی شده برای تحلیل تصاویر پزشکی

### ویژگی‌های پیشرفته آموزش
- **افزایش داده**: برش‌های تصادفی، چرخش، تغییر رنگ، پاک‌سازی تصادفی
- **مدیریت عدم تعادل کلاس**: نمونه‌برداری وزن‌دار و تابع زیان وزن‌دار
- **زمان‌بندی نرخ یادگیری**: ReduceLROnPlateau برای یادگیری تطبیقی
- **برش گرادیان**: جلوگیری از انفجار گرادیان‌ها
- **توقف زودهنگام**: توقف خودکار زمانی که اعتبارسنجی بهبود نمی‌یابد
- **ذخیره‌سازی مدل**: ذخیره بهترین مدل بر اساس دقت اعتبارسنجی

### ارزیابی و تصویرسازی
- گزارش طبقه‌بندی (دقت، بازخوانی، F1-score)
- تصویرسازی ماتریس درهم‌ریختگی
- نمودارهای تاریخچه آموزش (منحنی‌های زیان و دقت)
- معیارهای دقت به تفکیک کلاس

### شتاب‌دهی سخت‌افزاری
- **پشتیبانی MPS**: استفاده از شتاب‌دهی GPU در Apple Silicon
- **اندازه دسته بهینه**: پیکربندی شده برای حافظه Mac M4

## 🏗️ معماری مدل

### نمای کلی DenseNet121

```
ورودی (224×224×3)
    ↓
DenseNet121 Backbone (پیش‌آموزش داده شده روی ImageNet)
    ↓
Global Average Pooling
    ↓
لایه کاملاً متصل (1024 → 3)
    ↓
Softmax
    ↓
خروجی (3 کلاس)
```

### آمار مدل

- **تعداد کل پارامترها**: 6,956,931
- **پارامترهای قابل آموزش**: 6,956,931
- **اندازه مدل**: ~30 مگابایت
- **اندازه ورودی**: 224×224×3
- **کلاس‌های خروجی**: 3 (عاج، مینا، پالپ)

### استراتژی یادگیری انتقالی

1. **Backbone**: DenseNet121 پیش‌آموزش داده شده روی ImageNet
2. **تنظیم دقیق**: تمام لایه‌ها با نرخ یادگیری متفاوت قابل آموزش
3. **Classifier**: لایه کاملاً متصل جدید برای 3 کلاس
4. **بهینه‌سازی**: AdamW با وزن‌کاهی

## 🔧 رفع مشکلات

### مشکلات رایج

**1. MPS در دسترس نیست**
```
Using device: cpu
```
**راه‌حل**: اطمینان حاصل کنید که روی Mac با Apple Silicon و macOS 12.3+ اجرا می‌کنید

**2. کمبود حافظه**
```
RuntimeError: MPS backend out of memory
```
**راه‌حل**: اندازه دسته را در `train.py` کاهش دهید:
```python
batch_size = 8  # کاهش از 16
```

**3. مدل یافت نشد**
```
FileNotFoundError: Model file not found: best_densenet_model.pth
```
**راه‌حل**: ابتدا مدل را آموزش دهید:
```bash
python train.py
```

**4. خطاهای Import**
```
ModuleNotFoundError: No module named 'torch'
```
**راه‌حل**: محیط مجازی را فعال کرده و وابستگی‌ها را نصب کنید:
```bash
source .venv/bin/activate
pip install -r requirements.txt
```

**5. تصویر یافت نشد**
```
❌ Image not found: path/to/image.png
```
**راه‌حل**: مسیر تصویر را بررسی کرده و اطمینان حاصل کنید که فایل وجود دارد

```python
        img_path = os.path.join(image_dir, img_file)
        result, detection = detect(img_path)
        print(f"{img_file}: {detection[4]} ({detection[5]*100:.1f}%)")
```
